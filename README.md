# Adesola Sobambo — Data Analytics Portfolio

A live business intelligence and data analytics portfolio showcasing verified case studies, an honest account of AI-assisted development, and a direct path to contact for freelance and contract work.

**Live app**: https://adesolasobambo.lovable.app

## What's Here

- **Home**: proof snapshots from two real analytics projects
- **Case Studies**: Telco Customer Churn Analysis and Superstore Sales Performance Dashboard, both built during the AnalystLab Africa Data Analytics Internship
- **How I Work**: an honest breakdown of where AI assists in the process and where judgment stays mine
- **Contact**: direct inquiry form for data analytics projects
